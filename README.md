# polymarket-weather

Research and trading work focused on extracting durable net PnL from Polymarket weather markets.

## Thesis

Weather markets are unusually attractive because the settlement variable is generated by physical systems with deep, continuously updating forecast and observation data, while prediction-market attention is uneven across cities, horizons and market types.

The project searches for edge in six places:

1. exact-resolver forecast calibration;
2. same-day observation-conditioned extrema;
3. model/observation release latency;
4. cross-bucket and negative-risk structure;
5. profitable-specialist wallet flow;
6. maker/taker execution economics.

The target is **net executable expected value and realized dollar PnL**, after spread, fees, slippage, fills, capacity and capital lock.
