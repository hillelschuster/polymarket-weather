# polymarket-weather

Research-first project for finding durable, executable edge in Polymarket weather markets.

**Objective:** maximize long-run realized net PnL from weather markets using better probability estimation, better settlement-source modeling, better timing, and better execution.

No trading implementation yet. The current phase is deliberately documentation and research only.
